# Voting Rules in Python

**By:** Oluwanifemi Olajuyigbe and Sara Saad

## Overview

Implementation of voting rules for the Decision Modeling assignment.

## Dataset Generation

To generate the election dataset, run:

```bash
python3 data/generate_dataset.py
```

This creates `data/election_data.csv` with the example dataset from the PDF (n=27 voters, m=4 candidates).


## Running the Code

To run all voting rules with the example dataset:

```bash
python3 voting_rules.py
```

This will test all questions
